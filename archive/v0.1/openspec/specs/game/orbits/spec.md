# Orbits

Orbital mechanics, flight physics, celestial bodies, and trajectory prediction for a 2D space game with 1:1 real-scale simulation.

## Capabilities

- [Celestial Bodies](celestial_bodies/spec.md) - Solar system bodies, gravity, Kepler equation solvers
- [Ship Physics](ship_physics/spec.md) - Ship state machine, thrust, rotation, Velocity Verlet integration, collision detection
- [Orbital Mechanics](orbital_mechanics/spec.md) - State vector to orbital element conversion, orbital info
- [Patched Conics](patched_conics/spec.md) - Trajectory prediction across SOI boundaries
