## Contracts

- **Loading screen (PLUME) and saves (REVERT):** every replacement of the game (start, new flight, load, revert) goes through `GameCommand`'s replace path (`commands.rs`: "Replace the game with a (checked, non-empty) save"). PLUME shows the loading screen after any replacement and at start, with the clock held, until the scene is ready; REVERT keeps using that path, so PLUME needs no hook from it.
- **Files:** PLUME owns `scene/exhaust*`, `exhaust.wgsl`, `terrain/`, a new loading module. MENUS owns `interface/` (except `interface/pause.rs`), `systems_screen/`, `navball/`, `scene/pick.rs`, `comms.rs` and the sim's comms routing if the Via flicker is there. The lead owns `interface/pause.rs`, `saves.rs`, `persist.rs`, `commands.rs`, `state.rs`, `staging*`, `sim::save`, `sim::systems` (propulsion, command, sequence). Shared (`main.rs`, `interface/mod.rs`): small edits, committed at once.
